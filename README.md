# PlatiMarket

Статический сайт платёжного сервиса (HTML/CSS/JS, без сборки) — кошелёк, обмен валют
и инструменты для бизнеса (приём платежей, массовые выплаты, API). Функционально
ориентирован на сервисы вроде Capitalist.net, но с собственным брендом, текстами и
дизайном — логотипы и фирменный стиль чужих сервисов здесь не используются.

Откройте `index.html` в браузере или запустите `python3 -m http.server`.

## Статус

Это **демо фронтенда**: все данные (курсы, тарифы, баланс, список операций) — заглушки
из `js/config.js` и `js/api.js`. Регистрация/вход ничего не сохраняют и не отправляют
на сервер. Приём настоящих платежей не ведётся.

## Структура

- `index.html` — главная (кошелёк+обмен, как это работает, тизеры для частных/бизнес клиентов, FAQ).
- `individuals.html` — кошелёк для частных клиентов: конвертер, способы пополнения/вывода, лимиты.
- `business.html` — инструменты для бизнеса: приём платежей, счета, массовые выплаты, варианты аккаунта.
- `api.html` — обзор API для разработчиков (эндпоинты, пример запроса/ответа — ориентир для бэкенда).
- `fees.html` — тарифы и лимиты.
- `security.html` — безопасность и уровни верификации.
- `faq.html`, `contacts.html` — вопросы и контакты.
- `cabinet.html` — форма входа/регистрации (заглушка; полноценный личный кабинет — следующий этап).

## Где что менять

- `css/style.css` — вся палитра, радиусы, тени и отступы в `:root`.
- `js/config.js` — название, навигация, контакты, валюты и демо-курсы, тарифы, лимиты, способы оплаты, FAQ.
- `js/icons.js` — набор inline-иконок (можно заменить на свою библиотеку).
- `js/ui.js` — рендер хедера/футера/FAQ, мобильное меню, анимация появления блоков.
- `js/app.js` — конвертер валют, таблицы тарифов/лимитов, форма личного кабинета.
- `js/api.js` — здесь собраны все обращения к будущему серверу (сейчас демо-заглушки).
- `assets/` — логотип.
