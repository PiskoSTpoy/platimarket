# PlatiMarket

Сайт и бэкенд платёжного сервиса — кошелёк, обмен валют и инструменты для бизнеса
(приём платежей, массовые выплаты, API). Функционально ориентирован на сервисы вроде
Capitalist.net, но с собственным брендом, текстами и дизайном — логотипы и фирменный
стиль чужих сервисов здесь не используются.

## Запуск

```
npm install
cp .env.example .env   # и задайте свой JWT_SECRET
npm start
```

Сайт и API поднимутся на одном сервере: http://localhost:3000. Для простого просмотра
только статических страниц (без личного кабинета) подойдёт и `python3 -m http.server` —
но кнопки «Войти»/«Регистрация» и `dashboard.html` работают только через `npm start`.

## Статус

- **Реально и сохраняется на сервере**: регистрация, вход (JWT в httpOnly cookie,
  `server/auth.js`), баланс по валютам, обмен между валютами (пересчёт на сервере,
  `server/currencies.js`), история операций — всё в SQLite (`server/db.js`,
  файл `server/data/platimarket.db`, создаётся автоматически).
- **Демо-режим**: пополнение зачисляется мгновенно без настоящего платёжного провайдера;
  заявка на вывод списывает баланс и переходит в статус «в обработке», но не уходит
  реальным переводом. Это явно показано в интерфейсе (плашка сверху, подписи у форм).
- **Ещё не реализовано**: приём платежей и массовые выплаты для бизнеса
  (`API.createInvoice()` / `API.createMassPayout()` в `js/api.js`) — остаются
  заглушками до интеграции с платёжными провайдерами.

## Структура

- `index.html`, `individuals.html`, `business.html`, `api.html`, `fees.html`,
  `security.html`, `faq.html`, `contacts.html` — статические страницы сайта.
- `cabinet.html` — вход/регистрация (реальные, через API).
- `dashboard.html` — личный кабинет: баланс, обмен, пополнение, вывод, история операций.
  Требует авторизации — без неё редиректит на `cabinet.html`.
- `server/index.js` — Express-приложение: API-роуты (`/api/...`) и раздача статики сайта.
- `server/db.js` — SQLite (better-sqlite3): схема (`users`, `balances`, `transactions`) и запросы.
- `server/auth.js` — хеширование пароля (bcrypt) и JWT-сессии в httpOnly cookie.
- `server/currencies.js` — серверная копия списка валют/курсов/комиссии для пересчёта
  (клиентским суммам не доверяем).

## Где что менять на фронтенде

- `css/style.css` — вся палитра, радиусы, тени, отступы и типографическая шкала в `:root`.
- `js/config.js` — название, навигация, контакты, валюты и демо-курсы, тарифы, лимиты, способы оплаты, FAQ.
- `js/icons.js` — набор inline-иконок.
- `js/ui.js` — рендер хедера/футера/FAQ, мобильное меню, анимация появления блоков.
- `js/app.js` — виджеты сайта: конвертер на главной, таблицы тарифов/лимитов, форма входа/регистрации.
- `js/dashboard.js` — логика личного кабинета (баланс, обмен, пополнение, вывод, история).
- `js/api.js` — клиент к `server/index.js` (регистрация/вход/баланс/обмен/пополнение/вывод — реальные; счета и массовые выплаты — пока демо-заглушки).
